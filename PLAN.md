# Intelligence — product direction

A local-first Linux workspace combines private conversations, persistent writing, organized work and a tool-capable assistant. Ordinary user actions remain deterministic; models use structured native tools through live permissions, revisions and approvals.

The release includes the implemented workspace described in README.md. Future work follows explicit user requests and the remaining release checks in TODO.md. Keep the app useful at 1080p, preserve offline work, and avoid features that require remote accounts when a local path exists.

No models are bundled during packaging. Cloud inference/search remain deliberate user configurations. Background work, decorative motion and host terminal access are separate controls. Product changes must preserve user data and meaningful native scope boundaries.
