# Agent skills

Skills are reusable Markdown procedures with profile ownership/scope, triggers and bounded relevant loading. Automatic, Review first and Off control learning. Inspect existing relevant skills before creating duplicates; keep procedures general and omit secrets/one-off private facts.

Only the owner can revise an editable generated skill at its current revision. Profiles can exclude skills/connections/tool categories. Temporary/read-only/log/report runs do not grant skill creation.

Skills are subordinate to mandatory guidance and live native authority. They cannot grant tools, change personality controls or authorize host/file actions by themselves.
