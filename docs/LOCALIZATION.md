# Language

English is the default; Settings → Look & feel offers Romanian. Visible labels, accessible names, hover/focus explanations and native dialog strings use localized keys. Themes and background layers retain the same controls and meaning in both languages.

User-authored notes, tasks, titles, messages and prompts remain as written. Do not translate them automatically as a UI migration. Verify long labels, wrapping, native fonts/scaling and keyboard traversal on the target host.
