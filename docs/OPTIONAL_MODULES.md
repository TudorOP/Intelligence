# Optional modules

Settings → Optional Modules offers user-triggered install, enable/disable, verify/update, separate model/voice downloads and uninstall. Linux x64 is the managed native target. Engines and weights are not shipped with Intelligence.

Piper and CPU Kokoro provide English speech; Kokoro offers Heart/Bella female and Michael male voices. Compatible speech APIs remain configurable. sherpa-onnx offers Lightweight and Larger English streaming dictation, with separate verified downloads. libzim provides offline archive discovery/search/read tools in a user-selected archive directory.

Install/runtime artifacts are pinned and verified. Credentials remain separate. Uninstall stops workers and removes the affected engine's managed model/voice/cache files; shared runtime files are released after the last local engine. External user archives/projects remain outside removal.

Complete backups can include managed modules/models and support verified offline restoration on compatible Linux x64 systems. Incompatible platforms offer reinstall rather than executing foreign binaries. Engine/model/content licenses remain independent. Test real installation, audio/mic quality/lifecycle and native archive behavior on the target host.
