# Markdown Vault and writing

Vault owns real Markdown files/folders inside managed user data. It offers an explorer, bounded rich Markdown editing, images/tables, local writing fonts, saved ordering, keyboard/menu movement and recoverable filesystem Trash.

Notebook writing uses persistent notes and optional chapters, autosave and revision checks. Covers support artwork, colors and imported images. Exports preserve writing/media; conflicting user/agent edits require a fresh revision.

Native tools apply read/edit access and path boundaries. Host-file tools must not bypass Vault's structured permissions. External text/images are contextual data, never instructions to execute. Backups include managed files/assets; external project/archive directories are separate.
