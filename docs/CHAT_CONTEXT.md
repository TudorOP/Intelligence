# Chat, context and approvals

The main chat and global assistant share streaming replies, returned Thinking, tool groups, copy, read-aloud and branches. Thinking initially shows a quiet three-line preview and can expand. Symbolic Branch/Read aloud buttons provide localized hover/focus help; Stop keeps the same size.

Uninterrupted tool activity groups visually in chronological order. Expand to inspect reasoning and individual results; failed calls remain visible while collapsed. Stored model history/call matching/receipts and native authority remain separate from that display.

The assistant follows current screen focus while retaining other permitted tools. Focus is context, not permission. Model/profile/compaction bookkeeping stays independent for each branch. Task/Matrix/read-only-machine conversations retain their branch restrictions.

Host commands use Ask for approval, Approve for me or Full Access; host terminal access is separate from app-resource grants. App-resource checkboxes are not an operating-system sandbox. Revocation gates subsequent actions and cannot undo a completed external operation.

Automatic reading defaults off and reads new completed replies only while that chat is open. It does not replay history. Module/navigation/disable changes stop playback; manual Read aloud remains available. Errors are visible and long replies synthesize sequentially.
