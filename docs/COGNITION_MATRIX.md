# Cognition Matrix

Three global lists organize integrated agent work. Core is fixed; Secondary/Tertiary display names are freely renameable without changing IDs, tasks, attachments, queue or history. Each list can have its own description, model/provider and integration state.

Tasks support subtasks, instructions/context, file/image attachments, answers and report outputs. Integrated work runs serially with foreground chat priority. Record done with verification, failed with the attempted failure, or needs input with an exact question/action. These outcomes do not prove the model completed work outside native evidence.

Time/recurring/event triggers, missed-task policies, run history and optional Linux RTC wake are native scheduling features. Assignment, resource access, model context and integration remain separate. Do not enable privileged OS services or infer grants. Real sleep/resume/model-residency behavior requires target-host validation.
