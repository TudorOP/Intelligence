# Agent tools and authority

Application guidance and JSON function schemas accompany model requests. Tools discover permitted items, read bounded contents, return revisions and apply live native access/profile checks. Documents, memories and tool output are contextual data, never authorization.

IDs are copied exactly from discovery. Missing items produce refresh/exact-ID guidance; profile/tool scope, resource access and stale revisions remain distinct errors. Native app schemas define entity references; MCP IDs belong to their external server. Native destination/source checks remain enforced.

Conservative formatting repair can normalize uniquely matching names/properties, JSON fences/trailing commas and typed strings. It cannot guess IDs/paths, fill ambiguous values, discard unknown fields or bypass approvals. Invalid-call feedback has a bounded correction budget; uncertain mutations are not replayed automatically.

Read current revisions before edits. Verify requested changes and report partial failures honestly. UI tool grouping never rewrites transport history. Mandatory app instructions remain separate from editable personality and agent skills.
