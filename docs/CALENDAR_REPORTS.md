# Calendar and Reports

Calendar offers personal, combined and agent views. Ordinary chats are excluded; task/report execution remains visible. Personal events support local-time/timezone recurrence and retain edit/revision checks.

Reports provide templates, one-off generation, configurable agents/sources/date coverage and recurrence, an automatic-work gate and a persisted library. The reader offers Overview, complete Report, Source references and isolated Chapters. Wrapped/fenced structured report output is formatted into readable prose; source references remain evidence, not model authority.

Report generation is read-only against its selected permitted sources. Saving/reading a schedule does not itself start inference. Background work pauses with the shared AI gate. Trash/restore retains source permissions and supplied revision conflicts; interrupted/uncertain runs need review. Validate live source/provider behavior on the target host.
