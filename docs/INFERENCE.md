# Model providers

Choose Ollama, LM Studio, OpenAI, Mistral, Qwen, OpenRouter or an OpenAI-compatible API. Local defaults are http://127.0.0.1:11434 and http://127.0.0.1:1234. Compatible APIs accept a configurable base URL, optional protected authentication and discovered/manual model IDs.

Test the connection, discover models, select a model and use a tool-capable model for agent work. Providers differ in tools, reasoning, vision, context reporting and streaming; compatibility is not a guarantee that every model can complete a task.

Provider keys are protected by the desktop and bound to configured endpoints. Intelligence never silently changes to a cloud provider. Separate Matrix list model choices and profile defaults remain available. Cancellation, native permission checks and recorded outcomes apply across transports.
