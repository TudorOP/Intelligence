# Security policy

Intelligence is under active development. Keep the application and its dependencies current and use the smallest assistant/tool scope that meets your needs. MCP servers and host tools can execute code when authorized; connect only tools you trust.

## Reporting a vulnerability

Use the repository's Security → Report a vulnerability option when available. If private reporting is unavailable, open an issue asking for a private reporting channel without including exploit details or private data. Do not publish API keys, credentials, databases, backups or personal conversation excerpts.

Include the affected version, operating system, relevant configuration, reproduction steps and potential impact using a minimal sanitized example. There is no guaranteed response time or security support commitment during development.

## Release status

This repository distributes source. Target Linux runtime, live provider/tool behavior and the exact binary/dependency/license audit remain required before application binary releases. Automated tests do not establish that every model or external tool will behave reliably.
